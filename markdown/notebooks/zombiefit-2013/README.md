# ZombieFit 2013

18 WODs from ZombieFit.org (June–July 2013), archived from the Wayback Machine. The final archived tiered sessions before the site went dark. Tiered sessions are split one file per level — `YYYY-MM-DD-beginner|advanced|expert.md` (Étudiant/Avancée/Traceur), each carrying the shared Warm Up and Cool Down plus a `level:` frontmatter property.

Entries are dated (`YYYY-MM-DD*.md`, frontmatter `date:`). Programming rotates through for-time, AMRAP, intervals, and max-effort formats, with a movement emphasis on parkour skills (quadrupedal movement, precision jumps), burpees, pull-ups, and bodyweight fundamentals.
