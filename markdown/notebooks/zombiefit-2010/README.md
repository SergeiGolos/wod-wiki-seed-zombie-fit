# ZombieFit 2010

656 WODs from ZombieFit.org (January–December 2010), archived from the Wayback Machine. The first full year, and the largest: anniversary and milestone posts (50,000 visitors, one-year anniversary) alongside the daily programming. Tiered sessions are split one file per level — `YYYY-MM-DD-beginner|advanced|expert.md` (Étudiant/Avancée/Traceur), each carrying the shared Warm Up and Cool Down plus a `level:` frontmatter property.

Entries are dated (`YYYY-MM-DD*.md`, frontmatter `date:`). Programming rotates through for-time, AMRAP, intervals, and max-effort formats, with a movement emphasis on parkour skills (quadrupedal movement, precision jumps), burpees, pull-ups, and bodyweight fundamentals.
