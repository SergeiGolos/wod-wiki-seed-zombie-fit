# ZombieFit 2012

199 WODs from ZombieFit.org (January–December 2012), archived from the Wayback Machine. Posting frequency tapers through the year as the site winds down. Tiered sessions are split one file per level — `YYYY-MM-DD-beginner|advanced|expert.md` (Étudiant/Avancée/Traceur), each carrying the shared Warm Up and Cool Down plus a `level:` frontmatter property.

Entries are dated (`YYYY-MM-DD*.md`, frontmatter `date:`). Programming rotates through for-time, AMRAP, intervals, and max-effort formats, with a movement emphasis on parkour skills (quadrupedal movement, precision jumps), burpees, pull-ups, and bodyweight fundamentals.
