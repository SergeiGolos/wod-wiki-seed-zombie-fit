# ZombieFit 2020

3 WODs from ZombieFit.org (April 2020), archived from the Wayback Machine. A short-lived revival posted to the archived site early in the COVID lockdowns. Tiered sessions are split one file per level — `YYYY-MM-DD-beginner|advanced|expert.md` (Étudiant/Avancée/Traceur), each carrying the shared Warm Up and Cool Down plus a `level:` frontmatter property.

Entries are dated (`YYYY-MM-DD*.md`, frontmatter `date:`). Programming rotates through for-time, AMRAP, intervals, and max-effort formats, with a movement emphasis on parkour skills (quadrupedal movement, precision jumps), burpees, pull-ups, and bodyweight fundamentals.
